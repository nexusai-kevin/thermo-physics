HIDDEN The hidden layer — 32 units, four memory groups

Each group of eight hidden units is tuned to one stored prototype. Whichever group lights up is the memory the machine believes it is seeing — and that belief is what rebuilds the free visible units.

Live correlation of the current visible state with each stored prototype. Associative memory works because the right basin pulls hardest. Tap a row to load that prototype.

How completion works

  1. 1Clamp what you know. The visible units you can see are locked to the partial pattern. The rest start unknown.
  2. 2Alternate. A Gibbs sweep passes the visible state up to the 32 hidden units, then passes their answer back down to rebuild only the free units.
  3. 3Settle into a memory. Each sweep sharpens the reconstruction until it locks onto a stored prototype — the blanks are filled by the memory itself.
