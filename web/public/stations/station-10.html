The model

H = − Σi<j Jij si sj,  si = ±1,  Jij ~ 𝒩(0, 1/N)

  • Dense couplings. Every spin talks to all 23 others — 276 bonds, each drawn from a Gaussian. Roughly half pull toward alignment, half against it.
  • Overlap. q = (1/N) Σ siA siB measures how alike two independently sampled copies of the same system are.
  • The dashboard's instance is one fixed draw of the couplings. Its ground state, −16.9836, was verified by enumerating all 224 configurations — the same exact check the benchmark reports.
